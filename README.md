# みつやと綴る、やさしいタイピング｜完成版 v1.0

INFJの宿木みつやと、言葉を「打つことで」会話する無料ブラウザゲームです。外部API・広告SDK・追跡ツールは使っていません。

## 内容
- 全10会話、各3つの返事
- **3候補をクリックせず**に、返答を日本語で直接入力
- 漢字かな交じり、ひらがな・カタカナ入力の両方に対応。空白・句読点不要
- 漢字IME変換中には確定しない
- 親密度・安心度・共鳴度・フラグによる**8エンディング**
- エンディング画像の拡大・WebP保存・ギャラリー・ブラウザ内解放履歴
- 通常、安心、不穏、閉塞の感情テーマ
- スマホ・PC両対応

## GitHub Pages でのアップロード
リポジトリ `mitsuya-typing` のルート直下に `index.html`、`style.css`、`game.js`、`assets` フォルダを配置します。`mitsuya-typing-complete` フォルダ自体をアップロードして一階層下にしないでください。以前の `index.html` は上書きします。`design-docs` は残して構いません。

GitHub → Code → Add file → Upload files → **ZIPを解凍したフォルダの中身**をドラッグ → Commit changes。Settings → Pages が `main` / `/(root)` になっていれば自動で更新されます。

## ファイルについて
- `index.html`: 起点
- `style.css`: デザイン
- `game.js`: 10話の物語・分岐・タイピングロジックを内蔵
- `assets/*.webp`: 最適化済みの生成イラスト
- `scenarios.json`: 編集用の物語仕様元データ（ゲーム実行時はJS内に内蔵）
- `assets.json`: 編集時に使用する画像対応表

## 入力仕様
- 日本語の文章を入力し、3候補のテキストもしくは読み仮名の先頭一致で候補を絞ります。
- どれか1つを**全文入力**したタイミングで返答を確定します。
- 空白・句読点（、。？！等）を比較時に無視します。
- 同じ冒頭の候補がある場合は、区別できる文字まで複数候補を残します。
- 誤入力時は進行せず、Backspaceで直せます。制限時間はありません。
- IMEの未確定文字を確定判定に使いません。
- このバージョンは **PC向けのローマ字キー1打ごとの速度測定** ではなく **日本語文章入力型** です。IME変換によりタイピング速度の計測は行っていません。

## コレクションについて
- 8エンドすべて到達可能な選択の組合せであることを全59,049通り検証済み。
- エンディングごとに異なる画像を割り当てています。人物の一部画像はプレイ中の素材と共通です。現段階では新規制作された専用CGが8枚すべてにあるわけではありません。
- セーブはブラウザの `localStorage` 内のみで端末間共有はありません。
- 制作データをGitHub上で公開すると誰でもその素材を閲覧できます。

## ローカルでの確認
解凍した `index.html` を開くか、ターミナルで `python3 -m http.server 8000` を実行して `http://localhost:8000/` にアクセスします。
