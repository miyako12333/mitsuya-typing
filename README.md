# みつやと綴る、やさしいタイピング v1.2

GitHub Pages用の完成版差し替えデータです。ZIPを解凍し、中の `index.html` / `game.js` / `style.css` とその他ファイル・`assets` フォルダをリポジトリの一番上へアップロードしてください。

## 主な変更

- 通常モードは **ひらがな・カタカナ・漢字まじり**の表記に対応（漢字読みのふりがなは各選択肢の `reading` を使用）。空白・句読点は任意。
- 上級モードは表示どおりの漢字・かな表記が必要（空白・句読点は任意）。
- モード変更時は入力途中の文章をリセット。
- プレイ開始からの経過時間を MM:SS で計測。結果にはプレイ時間、入力文字数、参考入力速度、入力ミスを表示。
- INFJのテーマと10の具体的なシチュエーション、会話後の任意で読めるコミュニケーション解説を追加。
- キャラクター・画像・エンディング解放履歴は既存のものを引き継ぎます。

※ IME確定後に候補を判定します。タイピング速度は確定入力の文字数÷入力操作時間の参考値で、通常のローマ字キー打鍵数によるWPMとは異なります。

※ MBTI / INFJについての解説は架空の人物を通した会話ヒントです。個人の考え方を性格タイプだけで断定するものではありません。
