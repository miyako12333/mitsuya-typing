# みつやと綴る、やさしいタイピング v2.0 — 確認用ビルド

GitHub公開版は更新していません。このZIPはローカルでの動作確認用です。

## 追加したもの
- 70枚の景色イラスト、25本のHiggsfield日本語音声付き動画URL（エンディング11・途中イベント14）
- ゲーム中のイベント動画表示と、Enter・ボタンでのスキップ
- スキップしても解放履歴を保存。タイトル画面の「みつやの思い出」から解放済み25種類を再視聴
- 未解放の映像・タイトルはネタバレ防止で非表示
- 途中動画の自動表示ON/OFF設定。OFFでも解放条件を満たせば履歴に記録
- 親密度とプレイ回数に応じた段階的なイベント表示
- タイピング計測から動画・解説の時間を除外
- ブラウザのサイトデータ削除とセーブデータ消失についての説明

## 重要
- MP4自体はZIPに含まず、Higgsfield CloudFront URLへアクセスして再生します。動画URLの長期保存は保証されません。恒久公開時はMP4を自身の配信先に保存・差し替えてください。
- ブラウザのlocalStorageに記録します。ログイン・クラウド同期・バックアップ機能はありません。
- GitHub Pagesでは同一オリジンの既存保存データを読み込めますが、ローカル/別URLでの確認は別の記録になります。
- 自動再生はブラウザの制限によりブロックされる場合があります。その場合は再生ボタンで開始してください。
- 映像と日本語音声の内容・環境音の品質は、実際のブラウザで1本ずつ確認してください。
- 動画の途中イベントは周回・親密度・会話の状況で解放され、1周で25本すべてが流れるわけではありません。

## データ消失の説明
Cookie/サイトデータ削除、プライベートブラウズの終了、別ブラウザ・別端末利用で記録が消えたり引き継がれない場合があります。単純な画像キャッシュ削除だけでは必ずしも消えません。

## 品質確認と今後の課題
- Node.js構文検査と静的リソースの整合性検査済み。実機の通しプレイと端末別の動画再生確認は未実施です。
- 70枚画像とテキストの細やかな場面一致は要追加レビュー。画像は従来の周回順解放方式を維持しています。
- 動画を自身の配信サーバーへ移行する作業は残っています。外部ホストのままでGitHub公開は推奨しません。
