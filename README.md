# みつやと綴る、やさしいタイピング v1.4

## ゲームの更新内容

- 新タイトル画面：INFJを題材に、言葉の選び方を考えながらタイピングの速度・正確性を鍛えるというゲームの目的と遊び方を表示。
- 3択のいずれかを直接打つ（クリックによる選択は不要）。
- スタート画面でのみ入力モード選択。**やさしい**＝ひらがな、カタカナ、漢字交じりOK。**上級**＝表示の漢字かな表記どおり。両方とも空白・句読点は不要。
- 日本語IME変換中のEnterは入力確定用。返答後は **Enter** で次の会話に進む（最後はエンディングへ）。
- プレイ中と返答画面に「中断する」ボタン。確認後スタートへ戻り、既に解放した画像・自己ベストは保持。現在の途中経過は失われます。
- PC画面でスクロールせず3択と入力欄を使えるよう、会話画面をコンパクト化。極端に高さが小さい画面では画面内のスクロールが必要になる場合があります。
- 計測：プレイ経過時間 MM:SS、正確率、参考入力速度（確定文字/分）、最大連続ノーミス会話数のコンボ、最高記録、S〜Dランク。
- 10話30択、シーンの状況説明、みつやからの返事、任意のINFJ×コミュニケーション解説、8種のエンディング、ギャラリー、画像保存。

## GitHub Pagesへの更新

ZIP内の **index.html / game.js / style.css / scenarios.json / assets.json / assetsフォルダ** をGitHubリポジトリのトップ階層にアップロードし、Commit changesします。既存の `design-docs` フォルダは残して構いません。サイトのトップに `VERSION 1.4 · INFJ TYPING` が表示されたら更新成功です。

※ ZIPはGitHubにそのまま置くのではなく、解凍した中身をアップロードしてください。

## 動画への拡張

`game.js` の `ENDING_MEDIA` に動画ファイルの場所を追加すると、該当エンディングでは画像の代わりに音声付きMP4動画を表示します（例：`NORMAL:'assets/video/NORMAL.mp4'`）。動画が未収録のエンドは美しい静止画を表示します。全8本の動画の自動生成は含まれません。動画再生は利用者の操作で開始する設計です。

MBTI / INFJは会話を考えるための題材です。誰にでも当てはまる正解や性格診断ではありません。
